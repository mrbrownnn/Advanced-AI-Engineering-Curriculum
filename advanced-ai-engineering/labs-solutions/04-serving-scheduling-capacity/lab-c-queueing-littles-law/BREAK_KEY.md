# BREAK key — LAB C

Two common breaks are covered: including warm-up in measurement, and using full sojourns for requests that straddle a finite-window edge. Both mismatch the population/time boundary. Clip each residence to `[t0,t1)`, count zero-wait queue visits, and keep offered/admitted populations distinct when drops exist. At `rho >= 1`, Little's finite-window accounting still holds; the long-run steady-state interpretation does not.
